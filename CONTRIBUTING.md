# Contribuir

## Flujo

1. Elegir una tarea `READY`.
2. Crear rama.
3. Añadir criterios de aceptación.
4. Implementar.
5. Probar.
6. Actualizar documentación.
7. Abrir pull request.
8. No hacer merge sin revisión.

## Ramas

- `feat/...`
- `fix/...`
- `docs/...`
- `test/...`
- `chore/...`

## Commits

- `feat:`
- `fix:`
- `docs:`
- `test:`
- `refactor:`
- `chore:`

## Pull request

Debe indicar:

- problema;
- solución;
- archivos principales;
- pruebas;
- privacidad;
- screenshots;
- impacto en hoja de ruta;
- riesgos.

## Definition of Done

- compila;
- pruebas pasan;
- contrato respetado;
- logs seguros;
- UX de error;
- documentación;
- historial actualizado;
- no hay secretos.
