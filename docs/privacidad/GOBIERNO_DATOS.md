# Gobierno de datos

## Regla

El detalle pertenece al trabajador. La empresa recibe agregados.

## Niveles

### A — evento efímero local
Backspace/Delete, movimientos y cambios de ventana. Nunca sale.

### B — métrica personal
Score, feedback, historial y preferencias. Local.

### C — paquete agregado
Banda, ventana, intervención, resultado, organización y equipo. Nube.

### D — dashboard
Promedios, tendencias, distribución, muestra, incertidumbre y recomendación.

## Prohibido

- nombre;
- correo;
- ID laboral;
- captura;
- texto;
- aplicación;
- título;
- URL;
- archivo;
- mensaje;
- ranking;
- evaluación personal.

## Derechos

- pausar;
- salir;
- borrar;
- desactivar sensores;
- conocer qué se envió;
- no ser evaluado individualmente.
