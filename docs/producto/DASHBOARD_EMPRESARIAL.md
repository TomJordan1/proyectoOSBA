# Laminar Teams

## Objetivo

Mejorar procesos, no evaluar personas.

## Vistas MVP

- resumen grupal;
- tendencia semanal;
- fricción por periodo;
- tamaño de muestra;
- estado de privacidad;
- intervenciones agregadas;
- recomendaciones organizacionales.

## Prohibido

- personas;
- ranking;
- top/bottom;
- productividad;
- semáforo punitivo;
- alertas en tiempo real para grupos pequeños;
- diagnóstico.

## Lenguaje

Incorrecto: “El equipo está estresado.”

Correcto: “La fricción digital agregada aumentó respecto a la línea base semanal.”

Incorrecto: “El sprint causó agotamiento.”

Correcto: “El aumento coincidió con la semana de entrega; validar con el equipo.”
