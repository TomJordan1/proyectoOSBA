# Historias de usuario MVP

## HU-01 Detectar fricción

Como usuario, quiero que Laminar detecte cambios sin leer mi contenido.

**Aceptación:** no se almacena texto y puedo ver las métricas agregadas.

## HU-02 No interrumpir

Como usuario en reunión, quiero que Laminar permanezca silencioso.

**Aceptación:** con contexto protegido no aparece overlay.

## HU-03 Recuperación

Como usuario disponible, quiero una experiencia breve y no competitiva.

**Aceptación:** puedo salir y activar reducción de movimiento.

## HU-04 Comprender decisión

Como usuario, quiero saber por qué Laminar intervino.

**Aceptación:** cada acción muestra una explicación simple.

## HU-05 Modo offline

Como usuario, quiero que la app no falle sin internet.

**Aceptación:** fallback local y aviso no invasivo.

## HU-06 Demo pública

Como jurado o visitante, quiero entender y probar la lógica sin instalar.

**Aceptación:** simulador web con escenarios marcados como demo.
